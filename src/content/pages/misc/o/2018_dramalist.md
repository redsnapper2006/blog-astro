# 新参者

新参者  
东野圭吾粉必看的电视剧。一个新搬来的女子意外死亡，看上去被害前跟很多人都有过接触。  
男主角加贺恭一郎抽丝剥茧排除各种嫌疑者，最后定位到一个最意外的结果。  
客串的名角不少。

# ハゲタカ

秃鹰  
好久没看到这么精彩的商战电视剧了，个人感觉比《半泽直树》要好，半泽直树更多地把笔墨放在了复仇上了。  
而这部电视剧根据原著的两个系列，改变成三段故事，分别是泡沫经济破碎时，经济复兴，和现在。  
里面赤裸裸展示了资本的黑暗运作，利益面前私欲纵行，多方的权钱交纵。  
难为男主角总能在绝境处逢生。

# ゼロ 一攫千金ゲーム

ZERO.一攫千金游戏  
很有《賭博黙示録カイジ》的风格，可惜拍成电视剧节奏上太松散了，人物众多导致主角不够突出。  
每集一个游戏，看上去很简单，当然也只是造成的假象，貌似很简单，结尾处都反转。说明作者确实下了工夫，认真思考，详细设计了游戏，而最后由男主揭露游戏的 match point。

# ミス・シャーロック

Miss.Sherlock  
夏洛克小姐。女版的福尔摩斯。地点从英伦搬到了东洋。福尔摩斯由男子汉变成了女汉子。华生医生也从兄弟变成了闺蜜。  
莫里亚蒂也是女演员演绎，但不是为了钱财而是为了理想，和福尔摩斯斗志斗法。  
其他诸如福尔摩斯的哥哥，女管家，乞丐都是和原著一样的人设。  
很多情节都参照原著，除了加入了东瀛和现代化的元素，让故事发展地更合理。  
当然肯定少不了最后的一跳，原著的两个基友的瀑布蹦极，变成了美女死党的高楼飞跃。  
PS，竹内结子演绎的夏洛克，很有女汉子的风范。

# もみ消して冬、わが家の問題なかったことに

Momikeshite.Fuyu.Wagaya.no.Mondai.Nakattakotoni  
家家有本难念的经，但是以轻喜剧方式表现出来，别有一番味道。家族成员轮流登场，各种问题冲突，好在一家人众志成城，总能在欢笑和眼泪中逆转。当然中间不乏主角光环的偶然性。家的意义也许就在于此，有哭有笑，有烦恼有欢乐，你拥抱不的，你也逃避不的。一切困难总能在各方面求的均衡的条件下得到解决。而其中起关键作用的是家族成员间的感情纽带，也正是这些纽带才能带领家族翻越千山万水。  
2018-03-21 Update  
最后一集太感人了。牺牲小我也未能阻止家族成员遭遇滑铁卢，从天堂滑落到地狱一瞬之间。但所有人都不离不弃，终得 Happy Ending。能享受过最好的，也能承受过最坏的。
