# Wonder Woman 1984

神奇女侠 1984  
漫威的10年，创造了一个闭环英雄传奇。压的DC喘不过来气。  
现在该DC扬眉吐气了吧，你倒是争点气呀。  
这个神奇女侠拍的是肿么了，和第一部比起来差的太多了。  
神奇女侠身穿射手座圣衣变身黄金圣斗士，告诫世人要断舍离。

# Greenland

末日逃生  
前半部分类似世界大战的情节，后半部分类似 2012 的情节。  
中间肯定少不了家庭亲情环节。  
情节乏善可陈，各个情节矛盾冲突都能找到在其他电影中的影子。  
彗星撞地球的科学假设也漏洞百出。不较真就好。

# 姜子牙

姜子牙  
借封神演义故事之手，讲述了一个底层志士反抗当权既得利益者的故事。  
有人面貌丑陋，但内心却善良。有人道貌岸然，但内心却狡诈。  
狐仙是妖？师尊是神？孰妖孰神，真不好说。  
有人的地方就有江湖。人人皆被利益、权利掩盖自己的双眼。  
贪癫痴慢疑，佛法五毒，凡人无人能摆脱。  
其实整个故事就是借了姜子牙的壳，脱离这个 IP，套用在别的故事上，一样不影响主旨。  
申公豹有别于原著，成了姜子牙的好基友。最后舍身完成自我的升华。

# 八百

八百  
根据真实事件改编。  
上海守了三个月还是丢了。最后一个据点是四行仓库，作为仅存的希望，拖住日军前进的脚步。  
因为与租界隔河相望，日军心照不宣地不敢越雷池半步，只能围住四行仓库。租界的人躺枪成了围观者。  
实际四百人，对外宣称八百人，顽强抵抗了四天。最后集体撤离到租界，为将来的战争保留了火种。  
四行仓库保卫战在于淞沪会战来说，实属小规模的守卫战。  
电影展现的很煽情，尤其是自报姓名、番号之后，拉响手榴弹，跳向日军方阵的一段。

# The.Outpost

前哨  
基于真实事件改编。  
开头情节有点苦闷，波澜不惊。经常基地组织有些小骚扰，成不了大气候。  
但是当官的走马灯似的换人，来了一茬，西游了一茬。  
最后三十分钟，直接跳跃到高潮。40 VS 400，虽然战术素养和武器装备占优，  
但弥补不了人数 10 倍的差距。电影镜头通过多主线方式交代，  
防爆车，战术指挥部，游兵散勇三条主线，交叉演绎。

# カイジ・ファイナルゲーム

赌博默示录 最终游戏  
三部曲的最后一部。  
前两部根据漫画改编，剧情很精彩，各种反转。而且十分烧脑。感叹作者的精心设计。  
这一部有点狗尾续貂的感觉，没有之前烧脑的设计。

# 1917

1917  
奥斯卡获奖影片，早早就看完了。一直没有写，拖延症呀！  
情节很简单，王二小送情报的故事。  
主要看点在一镜到底。中间用了所有的镜头衔接技巧，给人一股镜头不中断，  
情节推进连续的感觉。技巧确实用的好，看的很过瘾。也佩服所有人的努力。  
知道一镜到底有多难的，肯定能体会到这背后所有工作人员的艰辛。  
因为是战争题材，所以转场的镜头都是大开大合。  
从壕沟、战场中间地带到坑道，从花园、搭车转移到单枪赴任，从落慌逃跑、邂逅少妇到找到组织  
最后以集团军冲锋做背景的大场面映衬下，倚靠大树，孤赏夕阳，一切岁月静好收尾。

# Ava

艾娃  
劳模姐变身女杀手，陷入中年危机。  
工作（虽然是赏金杀手），家庭，和上司、同行的关系，恋情危机重重。  
几场打斗戏中规中矩，没有太出彩。  
陈冲客串了一个黑社会老大，算彩蛋。

# 記憶にございません！

不存在于记忆中  
日本有拿首相开玩笑的传统，以首相为背景拍的闹剧很多。  
这部是从失忆为切入点，泾渭分明的两种人格，形成鲜明对比。  
笑点大多来自前后反差对比。中规中矩，不够好笑。

# Extraction

惊天营救  
锤哥化身独立雇佣兵，背负失子之痛，孤身营救富二代。  
从开始世故地拿钱办事，到后来良心发现，舍身护送富二代脱困。  
颈部中弹，纵身一跳，完成自我救赎。  
片尾远景模糊的身影为续集留了一个尾巴。拭目以待吧。  
值得一提，中间那段长镜头，虽说是用了很多技巧，细心的人能看出来切换的痕迹。  
但是确实流畅，拳拳到肉，狭小的楼道空间到闹市的大开大合。这 feel 倍爽。

# 몽타주

蒙太奇  
蒙太奇，了解电影的同学都知道这个电影名词。  
同样的素材，剪辑的不同，编排的不同，导致最后的成片完全不同的效果。  
用蒙太奇的方式犯罪，还是头一次，还是用蒙太奇的电影来演绎蒙太奇的犯罪。  
犯罪悬疑片已成为韩国电影的一个标志。疑点重重，抽丝剥茧，山穷水尽，柳暗花明，成了惯用的套路。  
这部主线支线颇多，互相交织在一起。现实和回忆穿插，但是导演功力十足，并不会感觉到结构凌乱。

# 6 Underground

鬼影特攻：以暴制暴  
迈克尔贝的片子从来都是很爽的，这片也不例外。  
关键所有精力都放在爽上了，取悦观众了，故事性上就差强人意了。  
这片情节太太老套了。老规矩，不剧透。  
飞行特技表演，开场 20 分钟的飙车追逐，COSPLAY 逼供，慢镜头血浆迸出，  
摩天大楼跑酷，“磁悬浮”特效。  
各种花样，应有尽有。从头到尾不需要关心情节，热血沸腾，就是一个字，爽。

# 嘘を愛する女

爱上谎言的女人  
麻酱一如既往地阳光。  
高桥还是那张长的着急的脸。跑步进入大叔的行列。  
想起一个段子，  
A:有一部戏，跟美女演员合作，有床戏，想演么？  
B:我演，我演。  
结果高桥一生在ICU演床戏躺一生。  
一部n个人自我救赎的电影。  
高桥对曾经的家庭进行了救赎。和麻酱生活在一起，对麻酱无微不至地照顾。  
麻酱对自己的恋人进行了救赎。挖地三尺般的了解高桥的过去，憧憬她们的未来。  
侦探对自己的妻儿进行了救赎。早日回到妻儿的身边。  
引用一下里面的台词收尾。  
“大概，99.999%”  
PS，濑户内海真的很美。

# Midway

决战中途岛  
新瓶装旧酒，中途岛战役作为太平洋战争的转折点，多次搬上荧屏。  
一切源于突袭珍珠港，美帝的太平洋舰队筋骨大伤。  
美日的太平洋海上力量差距明显，美帝处于劣势，被动挨打。  
下一个桥段，远程起飞轰炸东京，不蒸馒头争口气，中国兄弟小小地帮了一下盟友。  
最著名的淡水工厂出问题的桥段，一笔带过，没有花大力气渲染。  
鱼雷换炸弹，炸弹换鱼雷的部分满血补足笔墨。  
总结起来，老生常谈，美帝赢在信息优势。  
南云忠一也没做错什么，除了有点优柔寡断。  
尼米兹一战封神。

# ザ・ファブル

杀手寓言  
冈田准一有点发福，身手不如当年 SP 敏捷了。  
不过好在这个是由漫画改编的，可以用 CG 来弥补。  
全程笑点不好笑，可能退隐杀手的心境我们理解不了。  
枪战耍酷是最大亮点。冈田还参与了动作设计。很过瘾。

# Knives.Out

利刃出鞘  
局中局，洞中洞。  
007 剥丝抽茧，找漏洞。  
队长苦心设局，聪明反被聪明误。  
富不过三代，打铁还要自身硬。  
不要进入自私自利的怪圈。  
好人终有好报。

# The.Finest.Hours

怒海救援  
Captain不管开飞船还是轮船，都是一把好手。  
都是让人放心，可以寄托的人。  
都是能知道方向，安全带你回家的人。  
2小时全程无尿点。  
自救者，人恒救之。

# アンダー・ユア・ベッド

我在你床下  
日本版的《别和陌生人说话》。  
女主角很清纯，演被家暴的戏很卖力，但是心疼女主角。  
高良健吾演男主，很闷，确实演出了没有存在感的普通人。  
sigh，其实野百合也有春天。一杯咖啡，留香 11 年。

# Terminator: Dark Fate

终结者：黑暗命运  
随着CG技术的提升，终结者也终于编不下去了。  
所以索性Reset，重新来过。  
约翰康纳直接领盒饭，来了一个新的女性救世主。  
女性，拉丁范，领导人民闹革命，全是新 IP，可以出好几集续集。  
州长的I won't be back 一句，算是给自己定上了谢幕的调调。  
半人半机器的，最后也领盒饭了，基于本片作为重新洗牌的铺垫，也不足为奇。  
接下来就看康纳老妈和新救世主的养成啦。
