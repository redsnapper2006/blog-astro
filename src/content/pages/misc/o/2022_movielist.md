# 万里归途

真实事件为背景，具体情节系虚构。  
全片为了张译而追的

# The Gray Man

灰影人  
奔着高司令去看的，结果是个大杂烩

# Im Westen nichts Neues

西线无战事

# 神探大战

Detective.vs.Sleuths  
林峰现在主攻反派

# コンフィデンスマン JP 英雄編

行骗天下 JP：英雄篇  
冲着长泽雅美而追的。

# 独行月球

一个男人和一个袋鼠在月球上的故事  
剧情很狗血，但某些情节很燃

# Bullet.Train

子弹列车  
今年爽片，Brad Pitt 还是很能打

# 长津湖之水门桥

第二部比第一部战争戏精彩

# The Bad Guys

坏蛋联盟

# Doctor Strange in the Multiverse of Madness

奇异博士2：疯狂多元宇宙

# Morbius

暗夜博士：莫比亚斯  
漫威宇宙第二支线开始。英雄都有点怂。

# Everything Everywhere All at Once

瞬息全宇宙在各种无厘头中，引申出来很深刻的哲学问题。  
灵魂三问，我是谁，我从哪里来，我要到哪里去。  
网友说，杨紫琼接了一个好活。这 IP 能做出来 n^n 个宇宙，怎么编怎么有。

# マスカレード・ナイト

假面之夜  
大神的片子必须跟。精彩不足，反转也不惊艳。

# The Batman

新蝙蝠侠  
暗黑模式下的文艺范的布鲁斯韦恩

# Death on the Nile

尼罗河上的惨案  
先入为主的原因，和老版比起来，差多了。神奇女侠也难逃厄运。

# Spider-Man: No Way Home

蜘蛛侠：英雄无归  
除了三代 SpiderMan 同场竞技，别无亮点。  
算给漫威多元宇宙拉低预期，从起跑线-100 米开始起跑。  
后面的电影即使平平，也无力吐槽了。

# ザ・ファブル 殺さない殺し屋

杀手寓言  
第二章有点狗尾续貂，不如前部打的干净利索，花样繁多。可能因为限制条件，不能杀人。

# Don't Look Up

不要抬头  
小李子和大表姐很卖力。梅姨完美地诠释了政治家的丑陋。凯特布兰切特 Fashion 犹在。
