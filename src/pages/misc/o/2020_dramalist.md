# 七人の秘書

七个秘书  
几个秘书大闹政坛，把黑暗势力拉下马的故事。  
一集灭掉一个坏人，最后大 BOSS 登场，然后组团打怪，反转灭。

# 十日游戏

十日游戏  
改编自东野圭吾的《绑架游戏》。源于一次过量吸毒致死，误以为过失伤人，  
起于一段精心设计的绑架伪装，终于坏人得到法律制裁，良心发现的人得到救赎。  
没有看过东野圭吾的原著小说，网上评论，小说要比国产改编的电视剧暗黑的多。  
小说中众人皆为恶人，所有人都是精致利己主义者。

# The Queen's Gambit

后翼弃兵  
NetFlix 就这点好，绝不墨迹。电视剧一口气拍完，一口气放完，免了追剧的辛苦。  
棋类游戏我一直很喜欢，虽然我是一个臭棋篓子。  
这部根据真人真事改编的，讲述国际象棋女世界冠军从一个单亲家庭的弃儿，天赋秉然，  
自学成才，目标感极强地走进国际象棋世界，在众多男棋手中间脱颖而出，拔得头筹。  
导演没有把众多笔墨放在了比赛当中，比赛反而成为了剧情的润滑剂。  
女主的心里成长，情感成长反而占据了大部分镜头。展现了棋手作为普通人的一面。  
不过女主这开挂的一生，让人很羡慕。看来天赋真的很重要。

# 沉默的真相

沉默的真相  
紫金陈的第二部作品被爱奇艺搬上银幕，同样是迷雾剧场。还是走的悬疑的路线。  
看到男主角是廖凡，无脑下载，个人就喜欢廖凡的那种颓废的感觉。  
廖凡属于外形不怎么样，但就是有能拿影帝的命。  
这篇同样迷雾重重，通过多方的设局，用一张老照片的拼图，唤起了对历史一桩命案的关注。  
时间过去太久，人证物证已经无从查讯。一个正义感十足的前检察官以生命的代价，  
把早已跑出圈外的邪恶势力重新拉回警察的视线内，事情早就不再是最初的诱奸少女，  
最后的暗网则是官商结合，贱卖国家优质资产，中饱私囊。  
正义也许迟到，但绝不会缺席。

# SUITS2

SUITS2  
实在是创作乏力，把剩饭拿出来再炒一遍。  
中间还因为疫情二次爆发中断了一段时间。  
剧情乏善可陈，要案件没案件，要爱情没爱情。  
纯为了织田裕二和铃木保奈美刷完。

# 半沢直樹2

半泽直树2  
半泽直树出第一部的时候，当时用万人空巷来形容一点不过分。作为日 9 的头牌，造就了周日晚上老实在家追剧的现象。  
这部延续了当年的风采，不过第二部从开始入题上感觉就有点怯场，导致前三集拿了小冲突对抗热热场。  
接着矛盾升华的有些突兀，从内部对抗直接跨越到对抗政界，不出意料，必然困难重重，当然这也符合半泽直树的人设。  
还有两个大佬下海支持，咖位很有来头，一个是行长，一个是常务，未来的接班人。  
结局就是 Happy Ending，挖出政党的幕后操控者，正所谓日本的打虎英雄。

# 隐藏的角落

隐藏的角落  
紫金陈的《坏小孩》为本，改编的电视剧。  
很黑暗，看完心情十分不好。  
秦昊以后算定格到这部剧上了，肯定会被问候“你看我还有机会么？”，“一起去爬个山！”

# BG ～身辺警護人～ Season 2

BG：贴身保镖 第二季  
木村大神狗尾续貂的作品，从另一个角度来说，说明现在日剧创作瓶颈，  
只能用老的 IP 炒冷饭。当然，SMAP 几个人解散单飞后，每个人发展的都不好。  
早没有了当年的辉煌，接的各种戏，综艺什么的也不是什么大制作。

# 世にも奇妙な物語 '20 夏の特別編

世界奇妙物语 2020 夏季特别篇  
三个故事，很一般。

# アリバイ崩し承ります

帮你推翻不在场证明  
滨边美波是女一，负责颜值和卖萌。  
安田显大叔在旁边默默地负责卖萌周边的技术支持。  
归为推理破案剧一类，但是推理逻辑十分模糊，很牵强。  
嫌疑犯的不在场证明也不严密，漏洞很多。  
利用当代刑侦技术，应该轮不到女主出场。

# トップナイフ・天才脳外科医の条件

顶尖手术刀：天才脑外科医生的条件  
天海女王的片子，一定要追。谁让人家是中年女演员的颜值担当。  
女王简直要把所有精英都演个遍。前有女教师，女主持人。今有脑外科女医生。  
片子一般，无外乎医患矛盾，家庭矛盾，同事矛盾。  
收获在于科普了脑外科知识。
